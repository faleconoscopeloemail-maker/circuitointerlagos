# Circuito Interlagos — site (amostra)

Prévia do site do **Circuito Interlagos – Guia Gastronômico e de Oportunidades em Interlagos e região**.

> ⚠️ Esta é uma amostra para demonstração: os estabelecimentos, ofertas, patrocinadores e apoiadores são **fictícios** e as imagens são **ilustrativas**.

## O que tem no site

- Apresentação do guia (500 exemplares, 50 estabelecimentos, 6 categorias)
- Lista de estabelecimentos com busca e filtro por categoria
- Página de cada parceiro com apresentação, contatos, benefício, regras e área de carimbo
- Ofertas em destaque
- Patrocinadores e apoiadores
- Seção "Seja parceiro" com formulário de contato (ainda sem envio)
- Avisos importantes

## Como ver

Abra o arquivo `index.html` no navegador. Ele é um arquivo único, com imagens e estilos embutidos.

Para publicar com GitHub Pages: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`**.
